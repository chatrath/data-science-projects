## Automated checks

GitHub Actions runs on pushes, pull requests, and manual dispatch. The workflow
tests NL-Ops with offline evaluation, runs the cohort unit suite with English
OCR data and CPU-only dependencies, and checks dashboard startup. It requires
no private course materials, database credentials, live models, or API keys.
View results under [Actions](https://github.com/chatrath/data-science-projects/actions).
